# Developer and agent resources — Aman Anu

These resources make Aman Anu's public portfolio easier for browsers, assistants, and developers to verify. Read [llms.txt](https://amananu.me/llms.txt) first, then use [llms-full.txt](https://amananu.me/llms-full.txt) for richer public context. The root markdown representation is available at [index.md](https://amananu.me/index.md).

Compatible browsers can expose two read-only WebMCP tools: `amananu_get_profile` for verified public profile context and `amananu_open_section` for portfolio navigation. The site does not provide a public REST API, API keys, OAuth, a sandbox, an MCP endpoint, SDK, CLI, payment service, or agent-to-agent action endpoint.
